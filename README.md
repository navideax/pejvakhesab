# Pejvak Hesab — نسخه ۱.۴.۰ (عضویت و فراموشی رمز داخل قالب)

## تغییرات نسخه ۱.۴.۰

### جدید
- **عضویت داخل قالب:** تب «عضویت» در صفحه حساب کاربری — کاربر با نام، ایمیل، شماره موبایل (اختیاری) و رمز عبور مستقیماً در قالب ثبت‌نام می‌شود و دیگر به صفحه پیش‌فرض `wp-login.php?action=register` نمی‌رود. پس از ثبت‌نام به‌طور خودکار وارد حساب می‌شود.
- **فراموشی رمز عبور داخل قالب:** لینک «رمز عبورم را فراموش کرده‌ام» — ایمیل بازنشانی حاوی لینکی به خود صفحه حساب کاربری است (با پارامترهای `rp_key` و `rp_login`) و کاربر بدون دیدن وردپرس، رمز جدید را در قالب تنظیم می‌کند. اگر ورود پیامکی فعال باشد، راهنمای «ورود بدون رمز با کد پیامکی» هم نمایش داده می‌شود.
- محدودیت امتیاز (Rate-limit) بر اساس IP برای ثبت‌نام و فراموشی رمز (ضد اسپم).

### نکته برای فعال‌سازی
- برای نمایش تب «عضویت» باید گزینه «عضویت» (Anyone can register) در **تنظیمات ← عمومی** وردپرس فعال باشد.
- ایمیل‌های بازنشانی با `wp_mail` ارسال می‌شوند؛ برای تحویل مطمئن از افزونه SMTP استفاده کنید.

## تغییرات نسخه ۱.۳.۰

### جدید
- **اسلایدر نرم‌افزارها** در چهار نقطه:
  - صفحه اصلی → بخش «نرم‌افزار حسابداری مناسب کسب‌وکار شما»
  - صفحه single نرم‌افزار → بخش «سایر نرم‌افزارها»
  - صفحه راهکار صنفی → بخش «پکیج پیشنهادی این صنف»
  - صفحه فروشگاه/آرشیو (اختیاری — فعال‌سازی با اعمال تغییر روی template-shop.php)

- **پنل تنظیمات جدید:** «اسلایدر نرم‌افزار» با این گزینه‌ها:
  - تعداد کارت در دسکتاپ (پیش‌فرض ۳)
  - تعداد کارت در تبلت (پیش‌فرض ۲)
  - تعداد کارت در موبایل (پیش‌فرض ۱)
  - پخش خودکار (Auto-play) فعال/غیرفعال
  - تأخیر پخش خودکار (میلی‌ثانیه)
  - چرخش بی‌پایان (Loop)
  - نمایش نقطه‌های ناوبری

### رفع باگ‌ها
- **RTL کامل:** استفاده از `scroll-snap` بومی مرورگر به‌جای `translateX` — بدون پرش در فارسی
- **SEO-friendly:** همه کارت‌ها در DOM باقی می‌مونن، گوگل ایندکس می‌کنه
- **غیرفعال‌سازی خودکار:** اگه تعداد کارت‌ها کمتر یا برابر تعداد نمایشی باشه، اسلایدر غیرفعال و به گرید معمولی برمی‌گرده
- **Swipe/Touch:** پشتیبانی از کشیدن با انگشت روی موبایل و ماوس روی دسکتاپ
- **Keyboard:** پیمایش با کلیدهای چپ/راست (با در نظر گرفتن RTL)
- **Autoplay هوشمند:** با ورود ماوس متوقف می‌شه، با خروج دوباره شروع
- **Resize مقاوم:** با تغییر اندازه پنجره، تنظیمات به‌روز می‌شه
- **MutationObserver:** بعد از رندر داینامیک کارت‌ها توسط main.js، اسلایدرها دوباره build می‌شن

### تغییر نکرده (هیچ تغییری)
- `softCard()` و `productCard()` در `assets/js/main.js`
- داده‌های `PH.software` و `PH.products` در `assets/js/data.js`
- `home.css`, `base.css`, `shop.css` — فقط `slider.css` جدید
- `components.js` (هدر/فوتر/مودال)
- همه قالب‌های PHP دیگه

## نصب

1. کل پوشه رو روی `wp-content/themes/pejvak-hesab` جایگزین کن
2. از پیشخوان → «تنظیمات پژواک» → تب «اسلایدر نرم‌افزار» → تنظیمات رو دلخواه تغییر بده
3. اگه از کش استفاده می‌کنی، کش رو پاک کن

## نکات فنی

### SEO
- کارت‌ها همه در HTML اولیه رندر می‌شن
- `scroll-snap-type: x mandatory` بومی مرورگره — بدون dependency
- LCP تحت تأثیر قرار نمی‌گیره چون همه تصاویر lazy-load هستن

### مرورگرها
- Chrome/Edge 90+, Firefox 88+, Safari 14+, iOS 14+, Android Chrome 90+

### فایل‌های جدید
- `assets/js/ph-slider.js` (اسلایدر Vanilla JS)
- `assets/js/ph-slider-boot.js` (لودی config)
- `assets/css/slider.css` (استایل اسلایدر)

### توابع جدید در functions.php
- `ph_slider_open($track_id, $base_class, $variant)` — چاپ wrapper استاندارد
